# Pinch V2.3.0

开发者：Han。日期：2026-09-16。

## 更新

- 托盘右键新增“设置”：外观、压缩与保存、行为三页。
- 可设置浮窗底色、标题栏颜色、不透明度、输出大小上限、保存目录、置顶、通知和提示时长。
- 设置保存后持久化；取消不会改变当前设置。旧版窗口位置配置可迁移。
- 每个排队任务保留入队时的大小上限和输出目录。
- 支持 EXIF 1–8 旋转/镜像归一化与大小端属性读取，批量混合方向独立处理。
- 保留防覆盖输出、后台队列、单图失败继续、单实例唤醒、30 秒默认复位以及用户级安装/卸载。

## 验证范围

维护期间完成了方向、设置持久化、队列配置、取消保存、后台响应、安装回滚和卸载边界等回归。另用已安装的程序处理了 16 张方向测试图，逐张核对方向、宽高和原图哈希。

设置窗口三页已做 WinForms 渲染检查。不同 Windows 版本、高 DPI、多显示器和真实输入设备的完整兼容性仍需要在目标环境复测。

公开仓库中的 `Test.ps1` 可独立生成测试素材和执行回归；旧版本回滚数据已在 `tests/fixtures/legacy/` 提供。安装包及其 SHA-256 记录在 `releases/v2.3.0/`。

尚不支持 WebP、HEIC、AVIF。GIF 和多页 TIFF 只输出第一帧/页。源文件没有有效方向信息时，不进行基于内容的方向猜测。
